🕹️

Classic Gameplay

Waka your way through a 21×28 maze, gobble every pellet, dodge four relentless ghosts, and grab power pellets to turn the tables.

🧠

Real Ghost AI

Ghosts use greedy chase logic to hunt you down, then scatter randomly when frightened. Eat them for a 200-point bonus!

🎨

Full Color TUI

Rendered with ncurses color pairs — blue walls, yellow Pacman, and four distinct ghost colors. Falls back gracefully if your terminal has no color.

⚙️

Pure C, No Dependencies

Written entirely in C using only the standard library plus ncurses. One source file, one command to build. Runs anywhere with a terminal.

pacman — build & run
$ git clone https://github.com/cloudgpu/hola-apps.git
$ cd hola-apps
$ cc -Wall -Wextra pacman.c -o pacman -lncurses
✓ build complete
$ ./pacman
